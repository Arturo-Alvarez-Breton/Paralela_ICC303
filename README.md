## Instrucciones para el Proyecto Final

Para correr los diferentes escenarios del proyecto final, debes cambiar a la rama correspondiente de Git.

**Escenario 1**:
   Si deseas correr el **Escenario 1**, utiliza el siguiente comando para cambiar a la rama correspondiente:
   ```bash
   git checkout main-escenario1
```
**Escenario 2:**
Si deseas correr el Escenario 2, cambia a la rama principal con el siguiente comando:
   ```bash
  git checkout main
```


Para ejecutar el proyecto solo se necesita ejecutar:
   ```bash
  ./gradlew run
```
